# Data Redundancy Removal System

## About the Project
The Data Redundancy Removal System is a Python-based application that helps identify and remove duplicate data. It reduces unnecessary data storage and improves data management.

## Features
- Identify duplicate data
- Remove redundant records
- Reduce unnecessary data storage
- Simple and easy-to-use system

## Technologies Used
- Python
- PostgreSQL
- SQL

## Project Objective
The main objective of this project is to reduce duplicate data and improve data storage efficiency.
